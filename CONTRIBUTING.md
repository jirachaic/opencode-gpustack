# Contributing

1. Create or pick a tracked work item with the repository's `progress` workflow.
2. Install dependencies with `bun install`.
3. Add tests alongside behavior changes.
4. Run `bun run check` and `bun run build`.
5. Refresh the CocoIndex index with `ccc index` after structural changes.
6. Open a focused pull request and describe any compatibility impact.

Do not commit API keys, `.env` files, generated caches, or captured authorization headers.
