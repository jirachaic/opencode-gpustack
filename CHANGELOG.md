# Changelog

All notable changes to this project will be documented here.

## 0.1.0 - 2026-08-24

- Discover accessible GPUStack LLM routes from OpenCode.
- Support multiple GPUStack profiles and per-model overrides.
- Fall back to atomic last-known-good model caches.
- Provide initialization, discovery, synchronization, diagnostics, and cache CLI commands.
- Publish TypeScript plugin and type entrypoints on JSR.
- Add synchronized npm/JSR release automation and repository agent guidance.
